# Bruno Barlari Portfolio

Portfolio personal construido con React, TypeScript y Vite. La experiencia usa un tema claro con acentos pastel, ilustraciones tipo lapiz/acuarela y animaciones suaves de interfaz.

## Stack

- React + TypeScript
- Vite
- Framer Motion
- Lucide React
- Fontsource

## Scripts

```bash
npm install
npm run dev
npm run lint
npm run build
```

El servidor local corre por defecto en `http://127.0.0.1:5173/`.
